# Tipografías

Los archivos `.woff2` de esta carpeta vienen de Google Fonts y se distribuyen bajo la
**SIL Open Font License 1.1** (https://scripts.sil.org/OFL):

- **Public Sans** — USWDS / Dan O. Williams · https://fonts.google.com/specimen/Public+Sans
- **Fjalla One** — Sorkin Type · https://fonts.google.com/specimen/Fjalla+One

Se sirven desde el propio proyecto (y no desde el CDN de Google) para que la app
funcione sin conexión y no haga peticiones a terceros.
